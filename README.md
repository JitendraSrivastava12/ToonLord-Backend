<h1 align="center">📚 ToonLord – Manga Reading Platform (Backend)</h1> <p align="center"> <b>Scalable backend for a full-stack manga & comics ecosystem</b><br/> Authentication • Payments • Creator economy • Admin control • Recommendation engine </p>  <hr/> <h2>🌟 About ToonLord Backend</h2> <p> <strong>ToonLord Backend</strong> is a RESTful API built with <b>Node.js, Express, and MongoDB (Atlas)</b> that powers the ToonLord manga platform. It handles: </p> <ul> <li>User authentication & roles</li> <li>Manga & chapter management</li> <li>Coin economy & premium unlocking</li> <li>Creator monetization</li> <li>Admin moderation & revenue tracking</li> <li>Secure payment processing</li> </ul> <hr/> <h2>🧱 Tech Stack</h2> <ul> <li>Node.js</li> <li>Express.js</li> <li>MongoDB (Atlas)</li> <li>JWT Authentication</li> <li>Multer (file uploads)</li> <li>Cloud image storage</li> <li>Stripe API for payments</li> </ul> <hr/> <h2>✨ Core API Features</h2> <h3>📖 Manga & Chapter Management</h3> <ul> <li>Create, update, delete manga</li> <li>Upload chapters with image compression options</li> <li>Free & premium chapter access logic</li> <li>Reading progress & bookmarks</li> <li>Subscriptions & personal library</li> </ul> <h3>👤 Authentication & Roles</h3> <ul> <li>User signup & login</li> <li>JWT-based secure sessions</li> <li>Role-based access control: <ul> <li>Reader</li> <li>Creator</li> <li>Admin</li> </ul> </li> <li>Profile management</li> <li>Follow & following system</li> </ul> <hr/> <h2>✍️ Creator System</h2> <h3>📝 Creator Onboarding</h3> <ul> <li>Users apply to become creators</li> <li>Digital contract signing</li> <li>Admin approval workflow</li> <li>Creator role activation after approval</li> </ul> <h3>📂 Creator APIs</h3> <ul> <li>Upload manga & chapters</li> <li>Set image quality & compression</li> <li>Add external links to manga or chapters</li> <li>View creator analytics: <ul> <li>Views</li> <li>Earnings</li> <li>Subscribers</li> <li>Followers</li> </ul> </li> <li>Request premium status for manga</li> </ul> <h3>💰 Premium Manga Flow</h3> <ol> <li>Creator requests premium status</li> <li>Admin reviews request</li> <li>Admin issues contract</li> <li>Revenue split is defined</li> <li>Manga is marked premium</li> <li>Creator earns higher revenue per unlock</li> </ol> <hr/> <h2>🛡 Admin System</h2> <h3>📊 Admin APIs</h3> <ul> <li>User management</li> <li>Manga & chapter moderation</li> <li>Creator approval & contracts</li> <li>Premium request handling</li> <li>VIP subscription monitoring</li> <li>Revenue & transaction tracking</li> </ul> <h3>🚨 Report & Moderation</h3> <ul> <li>Users can report: <ul> <li>Manga</li> <li>Chapter</li> <li>Comment</li> <li>User</li> </ul> </li> <li>Admin can: <ul> <li>Review reports</li> <li>Delete content</li> <li>Warn users</li> <li>Ban users</li> </ul> </li> </ul> <hr/> <h2>💬 Comment System</h2> <ul> <li>Post comments on manga & chapters</li> <li>Threaded replies</li> <li>Like & interact with comments</li> <li>Report inappropriate content</li> </ul> <hr/> <h2>🧠 Recommendation Engine</h2> <ul> <li>Suggest manga based on: <ul> <li>Reading history</li> <li>Subscriptions</li> <li>Followed creators</li> <li>Popular titles</li> <li>Premium content</li> </ul> </li> </ul> <hr/> <h2>🪙 Economy & Payment System</h2> <ul> <li>Coin-based unlocking mechanism</li> <li>Coins earned via ads or purchase</li>
